# ПК-агент

Чат в браузере, в котором ИИ сам создаёт, читает и правит файлы на твоём компьютере: сайты, игры, документы Word и Excel.
Работает с DeepSeek и другими облачными сервисами, а также с локальными моделями (Ollama, LM Studio).

## Быстрый старт

1. Установи Python 3.9 или новее с python.org (галочка «Add to PATH»).
2. Запусти `start_chat.bat` (или `python agent_chat.py`). Перетащи папку проекта на `start_chat.bat`, чтобы она стала рабочей.
3. Вставь API-ключ или подключи локальную модель: окно подключения откроется само.

Дополнительно: `start_phone.bat` — доступ с телефона по Wi-Fi (покажет адрес и PIN-код),
`build_exe.bat` — сборка одного файла `PC-Agent.exe`.
Необязательно: Git (история и публикация), Chrome или Edge (автопроверка страниц), Docker Desktop (песочница).

## Как устроен код

```
agent_chat.py        запуск (тонкая обёртка)
run_tests.py         запуск всех проверок
pcagent/
  state.py           общее состояние (все остальные модули обращаются к нему как state.ИМЯ)
  util.py            безопасные пути, чтение файлов, дерево папки
  events.py          события для интерфейса и история отображения
  config.py          профили моделей (облако/локальная), режимы
  providers.py       подключение облачных и локальных серверов
  llm.py             запросы к модели (потоковый ответ, повторы)
  textmode.py        текстовый режим для моделей без вызова функций
  context.py         контроль размера чата, сжатие в конспект
  prompts.py         системные подсказки
  agent.py           главный цикл: шаги модели и выполнение инструментов
  autopilot.py       работа без вопросов к пользователю
  scheduler.py       расписание заданий
  persist.py         сохранение чата для каждой папки
  registry.py        список инструментов и вызов по имени
  fileops.py  shell.py  docs.py  webtools.py  browser.py  pagepreview.py  gitops.py  planning.py
                     сами инструменты агента
  telegram.py        Telegram-бот
  api_core.py  api_git.py  api_sched.py  api_tg.py  routes.py
                     команды, которые вызывает страница
  webserver.py  auth.py
                     HTTP-сервер и вход по PIN-коду
  app.py             запуск
  web/               index.html, style.css, app.js
tests/               автоматические проверки
```

Модули ссылаются друг на друга по имени (`fileops.confirm(...)`), поэтому циклические ссылки безопасны.
Всё изменяемое лежит в `state.py`.

## Проверки

```
python run_tests.py
```

Нужен только Python: настоящие модели, ключи и интернет не требуются, вместо них подставные серверы.
Проверяется основной сценарий, откат, выбор между моделями, автопилот, сжатие чата, документы,
git и публикация, расписание, Telegram, вход по PIN-коду, защита путей. Тесты, которым нужны git, node или Chrome, пропускаются, если их нет.

## Как добавить свой инструмент

1. Напиши функцию `t_имя(...)` в подходящем модуле (она возвращает текст для модели).
2. Добавь описание в `TOOLS` и функцию в `_build_impl()` в `pcagent/registry.py`.
3. Добавь подпись для Telegram в `prompts.TOOL_RU` (по желанию) и название в `NAMES` в `web/app.js`.
4. Напиши тест в `tests/`.
